# Agent roadmap

Planned features for custom GitHub PR agents. [Issues](https://github.com/Hyaxon/giad-agents/issues)
track the work; [Discussions](https://github.com/Hyaxon/giad-agents/discussions)
are for ideas and design choices.

- A minimal standalone agent template with protocol helpers and example fixtures.
- A short copy/edit/run guide, including model-free agents.
- Review-quality evaluation with defect and clean-PR fixtures.
- A measured quality baseline for the general code-review agent.
- Published agent images with source provenance and compatibility checks.
- MAGI: complementary review passes for correctness, requirements, and security.
- Wacht: dependency changes and vulnerability review using brokered advisory data.
- A deterministic analyzer that produces useful PR findings without a model.
- A documentation reviewer for broken examples, links, and source mismatches.
- Base/head test comparisons in test-summary.
- Small contributor tasks and agent artwork that fits GIAD's shared visual theme.

Test Writer, API compatibility review, broader audit agents, and catalog policy
remain ideas for discussion. Setup, execution, tools, and automatic publication
belong in the [runtime roadmap](https://github.com/Hyaxon/giad/blob/main/docs/roadmap.md).
